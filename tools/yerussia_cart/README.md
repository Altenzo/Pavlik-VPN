# add_to_cart.py — добавление товара в корзину (yerussia2026.ru)

Скрипт открывает страницу в Chromium (Playwright), находит кнопку «В корзину»
и нажимает её. Ничего не оплачивает и не оформляет — только корзина.

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

Если Chromium уже стоит в системе, браузер playwright можно не качать:

```bash
export CHROMIUM_PATH=/usr/bin/chromium      # или свой путь
```

## Запуск

```bash
# 1. посмотреть, что есть на странице (ничего не нажимает) — с этого проще начать
python add_to_cart.py --url https://yerussia2026.ru/ --dump

# 2. добавить в корзину
python add_to_cart.py --url https://yerussia2026.ru/<страница-товара>

# 3. три штуки + скриншот результата
python add_to_cart.py --url ... --qty 3 --screenshot cart.png

# 4. если автопоиск не угадал кнопку — задать её вручную
python add_to_cart.py --url ... --selector "button.product__buy"
python add_to_cart.py --url ... --text "Оплатить участие"

# 5. каталог/попап: сначала клик по карточке товара, потом по кнопке
python add_to_cart.py --url ... --card-selector ".t-store__card:first-child"

# 6. товара пока нет — ждать кнопку до 10 минут, перезагружая раз в 30 с
python add_to_cart.py --url ... --wait-stock 600 --reload-every 30

# посмотреть глазами, что происходит
python add_to_cart.py --url ... --headed --keep-open 30
```

Код возврата: `0` — товар добавлен, `1` — не удалось (причина печатается в JSON).

## Как это работает

1. Открывает страницу, закрывает cookie-баннер («Принять», «Согласен», …).
2. Читает счётчик корзины «до» (типовые селекторы Bitrix / WooCommerce / Tilda / InSales).
3. Ищет кнопку — сначала по вашему `--selector`/`--text`, иначе по списку
   типовых селекторов и текстов («В корзину», «Добавить в корзину», «Купить», …),
   в основном документе и во всех iframe. Берётся первый видимый и активный элемент.
4. Количество: если на странице есть поле количества — вписывает `--qty` и жмёт
   кнопку один раз; если поля нет — жмёт кнопку `--qty` раз.
5. Проверяет результат: счётчик корзины увеличился либо на странице появился
   текст вида «Товар добавлен в корзину».
6. Сохраняет cookies и localStorage в `cart_state.json` (`--state`), поэтому при
   следующем запуске корзина та же. Отключить — `--no-state`.

## Заметки

- Сайт `yerussia2026.ru` недоступен из окружения, где скрипт писался, поэтому
  селекторы конкретных кнопок не подставлены — автопоиск покрывает типовые
  варианты, а `--dump` показывает реальную разметку страницы, чтобы за минуту
  выбрать точный `--selector`.
- Проверено на локальных страницах-заглушках: счётчик корзины, поле количества,
  многократный клик, `--dump`, случай «кнопка не найдена».
- Скрипт рассчитан на обычную работу с корзиной (одна сессия, штучные клики).
  Не используйте его для массовой скупки ограниченных товаров и уважайте
  `robots.txt` и правила сайта.
